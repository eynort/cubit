■ Empieza en un minuto

Tres pasos

01

Instala

Linux: un comando, sin root. Windows: Scoop. macOS y Android: el programa de Releases.

$curl -fsSL …/latest/download/install.sh | sh # Linux
>scoop bucket add cubit https://github.com/eynort/cubit
>scoop install cubit/cubit # Windows
02

Abre el panel

Cubit, en el menú de aplicaciones, lo abre en el navegador. Guarda el enlace entero: lleva tu clave.

Menú: Cubit
Terminal: cubit --hub :8080 --open
Panel: http://localhost:8080/?t=…
03

Crea tu bot

Un asistente te pide nombre, servidor, dueño e idioma, y puede montarte un servidor de pruebas.

Nombre: Sentry
Servidor: Servidor de pruebas
Dueño: TuNombre
Minecraft: localhost:25565
