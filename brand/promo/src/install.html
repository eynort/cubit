■ Start in one minute

Three steps

01

Install

Linux: one command, no root. Windows: Scoop. macOS and Android: the binary from Releases.

$curl -fsSL …/latest/download/install.sh | sh # Linux
>scoop bucket add cubit https://github.com/eynort/cubit
>scoop install cubit/cubit # Windows
02

Open the panel

Cubit in your app menu opens it in the browser. Keep the whole link: it has your access key.

App menu: Cubit
Terminal: cubit --hub :8080 --open
Panel: http://localhost:8080/?t=…
03

Create your bot

A wizard asks for name, server, owner and language, and can set up a test server for you.

Name: Sentry
Server: Test server
Owner: YourName
Minecraft: localhost:25565
